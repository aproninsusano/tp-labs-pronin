1. Чем ветка отличается от копии папки с проектом?
Ветка — это легковесный указатель на определенный коммит. Она не создает копию всех файлов, а только указывает на изменения. Копия папки создает дубликат всех файлов, что занимает много места и не отслеживает историю изменений.
2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?
Если удалить папку проекта, но оставить папку .git, то все файлы проекта пропадут, но история коммитов останется. Можно восстановить все файлы на любой момент времени с помощью команды git checkout или git restore.
3. Зачем нужен Pull Request, если можно коммитить сразу в main?
Pull Request позволяет: (по овтетам с лекции)
- Проверить код перед слиянием 
- Обсудить изменения с вышестоящими менеджерами,
- Протестировать
- Защитить main или ветку от случайных ошибок
